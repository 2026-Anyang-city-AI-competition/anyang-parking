# 외부 라벨 재조사 — 결정 ③ 재검토

정본 §4 결정 ③(「안양까지만. 넓힐 데이터가 존재하지 않는다」)은 **공단 API 기준**이었다.
지자체 자체 개방 경로는 확인한 적이 없었고, 확인해 보니 **존재한다.**

```

serviceKey(필수) · laeId(선택)      ※ apiKey/key/authKey 는 인식 안 됨
```

## ★ 실시간 확인 (10분 간격 2회)

```
1차 09:34 · 2차 09:44
잔여면수 변동 375 / 810곳 (46%)
ocrnDt 갱신 806곳 (100%)   09:32:00.166 → 09:43:00.174
안양 89곳 중 변동 27곳
```

**진짜 실시간이다.** 공단 `PrkRealtimeInfo`(안양 0곳)와 달리 쓸 수 있다.

## ★ 우리 라벨의 정식 개방 경로

GITS 안양 89곳 ↔ 안양도시공사 포털 89곳: **이름 교집합 89/89 · 면수 일치 89/89.**
같은 원천이다. 「비공식 내부 API라 신청서 기재 금지」 제약이 해소된다.
→ 정본 §5 ①의 경고와 §14 의 해당 금지 항목을 갱신해야 한다. 공공데이터 배점 25점에 직결.

## 9피처 가용성 (실시간 노외 500곳 기준)

| 필드 | 채움률 | 대응 피처 |
|---|---:|---|
| `pkplcTypeNm` 노상/노외/부설 | 100% | `is_nosang` ← **공단에 없어 유형 자동판정이 실패했던 필드** |
| `pkplcDivNm` 공영/민영 | 100% | 모집단 분리 |
| `pklotCnt` | 100% | `log_cells` |
| `wkday/sat/hldy OprtStart·EndTime` | 100% | `open_hours` · `free_now` |
| `latCrdn`/`lonCrdn` | 99% | `compet_*` |
| `parkingBscFare` | 63% | 요금 |

없는 것: **급지**(표준데이터에만 존재). `grade` 는 이미 측정상 무용으로 제외된 상태다.

점유율 = `(pklotCnt - avblPklotCnt) / pklotCnt`  ※ 도시공사와 달리 **잔여**가 온다. 부호 주의.
