## 8. 원인 분해

ρ=-0.089 로 기준(-0.3)에 못 미친다. 원인 후보 3개의 무게를 근거와 함께 나눈다.

- **(a) 무료 lot 0곳 / 주말 부재** — 도시공사 89곳은 전부 유료라 lot 단위 무료 표본이 없다. 다만 운영시간 외 구간이 51%·64곳 확보돼 **`free_now` 로 무료 상태를 배울 재료는 이미 있다**(§7). 남은 결손은 주말(월, 화만 관측)뿐이다. → **(a)는 더 이상 주된 원인이 아니다.**
- **(b) 상권 피처 부재** — 현재 피처 12개 전부 공급·요금·경쟁 축이고, 수요 축(업종구성·인구·역거리)이 0개다. 정본 §7 C군이 통째로 빠져 있어 shape 을 설명할 변수가 원리적으로 부족하다.
- **(c) 진짜 전이 불가** — 프로파일 상관 자체의 평균이 +0.339 (무료 표본이 없어 그룹 내 비교 불가). lot 끼리는 패턴이 닮았는데 피처가 그걸 못 집는다 → (b) 쪽 무게가 크다.

**무게가 실리는 쪽: (b) 상권 피처 부재.** 어느 쪽이든 9/5~6 주말이 들어오고 상권 데이터를 붙인 뒤 재실행하기 전까지는 설계를 폐기할 근거가 되지 못한다. 정본 §8 판정일을 그때로 미루는 것이 맞다.
