# 모집단 확정 — 부설 vs 비부설

- 공단 안양 고유 **7,458곳** · 이름 있음 3,486 (47%) · 면수 중앙 **5면**
- 면수 분위 [3, 5, 11, 38, 645] → 소형 부설이 지배적인 분포다

- 앵커: 표준 107곳 중 **62곳**이 좌표 60m + 면수 ±25% 로 매칭 → 공단측 59행
  (좌표만 120m 로 보면 107곳 전부 매칭되지만, 옆 건물 부설이 잡혀 신뢰할 수 없다)

- 요금 신호: 운영정보 7,458곳 중 요금 필드가 **실제로 채워진 곳 55곳** (0.7%)
  운영시간도 같은 55곳만 값이 있고 나머지는 빈 문자열, `opertn_bs_free_time` 은 전 곳 `0` 상수 → 모집단 피처로 못 쓴다

## ★ 보고 숫자

- **비부설 추정 127곳** (확실) · 애매 1,188곳을 더하면 상한 1,315곳
- 부설 6,143곳 (82%) 은 예측 대상에서 제외

> ⚠️ **공단 안양 데이터는 사실상 건축물 부설주차장 대장이다.** 면수 중앙 5면, 53%가 무명이다. 비부설을 신뢰성 있게 골라낼 신호가 이름뿐이라 애매 구간이 크게 남는다.
> **요금 카드는 써봤고 거의 소득이 없었다.** 정밀도는 높지만(요금 있음 → 95% 가 비부설) 재현율이 낮아 애매 구간을 못 가른다.
