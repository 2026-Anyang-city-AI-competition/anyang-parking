## ★ 종합 — Δ 타깃 + L1 목적함수가 평일을 뒤집었다

**평일 (B_70, test = 금요일)** — 음수 = ML 승

| h | 레벨 타깃 | **Δ 타깃 + L1** |
|---:|---:|---:|
| 15 | +12% | **−2.8%** ✅ |
| 30 | −6% | **−10.1%** ✅ |
| 60 | −24% | **−26%** ✅ |
| 120 | −49% | **−47%** ✅ |

**→ 15·30분에서도 persistence 를 이긴다. T5 의 하이브리드 라우팅이 평일에는 불필요하다.**

### 두 가지가 각각 기여했다

**① 타깃을 Δ 로** — 레벨 분포 이동(평일 36.1±27.5 → 주말 49.7±38.5)을 우회한다.
주말 붕괴가 15분 +219% → +78% 로 줄었다(레벨 타깃 기준).

**② 목적함수를 L1 으로** — ★ 이게 더 컸다.
`LGBMRegressor` 기본값은 L2 인데 우리는 MAE 로 평가한다.
Δ 는 **15분 기준 63.3% 가 정확히 `0`** 인 뾰족한 분포라,
L2 는 조건부 평균을 좇아 잡음을 키우고(Δ̂ std 6.90) L1 은 조건부 중앙값 ≈0 에 붙는다(std 1.27).

| h=15 · 살아있는 67곳 | MAE |
|---|---:|
| Persistence (Δ̂=0) | **1.51** |
| Δ + L2 (기본) | 3.32 |
| **Δ + L1** | **1.72** |

주말까지 합치면 15분 +219% → **+22%** 로 10배 완화됐다.

### 지시서의 구조적 주장에 대한 정정

> "`delta_hat = 0` 이 정확히 persistence 다. 구조적으로 persistence 보다 나빠질 수 없다."

**복원식은 맞다** — `clip(occ + 0, 0, 120) == occ` 를 확인했다. 하지만 **결론은 성립하지 않는다.**
모델이 0 을 출력하도록 학습된다는 보장이 없기 때문이다.
실제로 L2 목적함수에서는 Δ̂ 가 평균 −0.77 · std 6.90 으로 크게 흔들려 persistence 의 2배를 졌다.
**"나빠질 수 없다"가 아니라 "목적함수를 맞추면 나빠지지 않는다"** 가 정확한 표현이다.

### 남은 것

주말은 여전히 못 이긴다(15분 +22%). **train 주말이 0% 인 B_70 의 한계**이고,
train 주말이 5.9% 인 A_80 에서는 상호작용 피처가 Δ 위에서 더 큰 이득을 낸다.
**9/12~13 주말이 쌓이면 재측정해야 한다.**
