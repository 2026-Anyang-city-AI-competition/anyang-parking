| | | **전혀 다르면** → 센서 고장. 22곳을 학습에서 빼야 한다 |

## 기록 방법

1. `data/raw/survey_template.csv` 를 폰이나 종이에 옮겨 적는다
2. **총면수도 현장에서 다시 센다.** 표기값이 틀릴 수 있다
3. 도착 시각을 **분 단위로** 적는다 — 폴링이 5분 격자라 매칭에 필요하다
4. 주차장 전경 사진 1장 (파일명을 시트에 기록)
5. 돌아와서:
   ```bash
   bash scripts/pull_vm.sh                       # 최신 회수
   .venv/bin/python scripts/snapshot_at.py "2026-09-05 14:30"
   ```
   → 「같은 시각, 데이터가 말한 값 vs 실제로 센 값」 표가 나온다. 발표자료로 직행한다
